# core requirements matrix

> Requirement matrix for the bio.viz **core**: the library's entry point, its two committed bundles, the vendored synthetic study, and the site that publishes them. Written with the repository setup ([bio.viz#1](https://github.com/jwildfire/bio.viz/issues/1); parent requirement [obot.roadmap#363](https://github.com/jwildfire/obot.roadmap/issues/363)) and extended with the study and the site's gallery, evidence pages and API reference ([bio.viz#7](https://github.com/jwildfire/bio.viz/issues/7); parent requirement [obot.roadmap#355](https://github.com/jwildfire/obot.roadmap/issues/355)). Design: [353_design.html](https://jwildfire.github.io/obot.roadmap/requirements/design/353_design.html), sections Repositories and Data the charts expect.

## Scope

What a page or a widget can rely on before any chart exists: the bundles are where the build says they are, they report the version they were built from, and nothing else is bundled into them. What every chart's demo and tests run on: the synthetic study, copied from gsm.bio and held to a record of where it came from. And what the site shows for every module: a gallery, an evidence page and an API reference. No chart and no statistics are in scope here; each chart and the connection to R gets its own matrix.

## Source inventory

- Task [bio.viz#1](https://github.com/jwildfire/bio.viz/issues/1), What changes and Definition of done.
- Task [bio.viz#7](https://github.com/jwildfire/bio.viz/issues/7), What changes and Definition of done; requirement [obot.roadmap#355](https://github.com/jwildfire/obot.roadmap/issues/355), Design.
- Design [353_design.html](https://jwildfire.github.io/obot.roadmap/requirements/design/353_design.html), Repositories: committed bundles; safety.viz needed on the page, not in the bundle; an evidence page per chart, a gallery. Statistics engine: webR loaded the first time a test is asked for. Data the charts expect: the three tables and their columns.
- Developer guidelines, Artifacts and pages: every page holds at a 390-pixel viewport with no horizontal scroll. Definition of done for a chart: gallery, evidence page (requirements, tests, screenshots), API reference.
- gsm.bio, `inst/extdata/synthetic_*.csv` and the documentation of `Synthetic_Results`, `Synthetic_Participants` and `Synthetic_Outcomes`.
- bio.viz source: `scripts/site-lib.mjs`, `scripts/api-lib.mjs`, `scripts/markdown-lib.mjs`, `scripts/evidence-lib.mjs`, `scripts/vendor-lib.mjs`, `tools/vendor-synthetic-study.mjs`.
