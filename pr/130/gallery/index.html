Charts 6 published

  • Group comparison

    Does this biomarker differ between these groups? A trend tile for every biomarker, then one biomarker across the visits or at one visit, with R's test of the groups.

    Demo · Evidence · API

  • Association scatter

    Do these two variables move together? One point per participant, coloured by a group, with R's Pearson or Spearman coefficient under it and R's linear fit or smooth over it.

    Demo · Evidence · API

  • Correlation matrix

    Which of these biomarkers, or which visits of one biomarker, are related? A grid of R's Pearson or Spearman coefficients, with no p-value, each cell opening its pair as a scatter.

    Demo · Evidence · API

  • Biomarker screen

    Across every biomarker, where is the signal? One row per biomarker, sorted by R's estimate, with its interval and its unadjusted and adjusted p-values.

    Demo · Evidence · API

  • Cross-tabulation

    Is this category associated with that one? A two-way table of counts and percentages beside stacked bars, with R's chi-square or Fisher's exact test.

    Demo · Evidence · API

  • Stratified survival Experimental

    The curves are safety.viz's Kaplan–Meier estimator, kmEstimate, which awaits its clinical review.

    Do participants with high and low levels of this biomarker have different outcomes? Kaplan–Meier curves per group above the biomarker's histogram, with R's log-rank test.

    Demo · Evidence · API

Demo data

Every demo and most tests run on one made-up study, generated in gsm.bio from a seeded model with known effects planted in it, so a test can assert an answer that is known in advance. No real participant is in it.
