Biomarker charts · every test computed by R

bio.viz 0.1.0

Charts for comparing groups and relating variables in biomarker data. They run beside safety.viz and reuse its shared parts. The library computes no statistical test itself: each one is asked of R.

The first chart

The gallery has the charts that are published, each with a live demo on a made-up study. A chart draws; it does not test. Every test is computed by R, and the charts say so where one would be printed.

What is in it

  • Library core

    The entry point and the two committed bundles, each reporting the package version, and the two steps every chart shares before anything is drawn: a variable named one way, and named variables resolved to one row per participant with what was left out counted.

    52 requirements · 141 of 141 test records passing · Requirement matrix

    Evidence · API reference

  • Connection to R

    The one call a chart makes to get a statistic from R, answered from results shipped with the page or by R started in the browser on first use, and the shared rule for printing a p-value with its method and counts.

    71 requirements · 164 of 164 test records passing · Requirement matrix

    Evidence · API reference

  • Group comparison

    Does this biomarker differ between these groups? One value across the levels of a category at chosen visits, as boxes, violins or points with the number in each group beneath, a second grouping by colour, panels by one further variable and a logarithmic scale. Click a box or a point to list its participants and open a participant's profile.
